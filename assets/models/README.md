# Jadefall character assets

This directory is reserved for production-ready glTF/GLB character models and animation clips.

The current browser prototype uses procedural Three.js characters so the repository remains lightweight and has no third-party character IP. For the intended visual target, replace these placeholders with original, licensed PBR glTF assets:

- player.glb — realistic wuxia wanderer
- lantern-keeper.glb — elderly village NPC
- ren-yue.glb — wandering swordswoman
- old-bo.glb — merchant
- mist-wraith.glb — supernatural enemy
- reed-bandit.glb — human enemy
- moonfang.glb — fox-like creature
- bell-warden.glb — boss

Recommended production assets: 20k–60k triangles for hero characters, 8k–20k for NPCs/enemies, 2k/1k/512 texture LODs, normal + roughness + metallic maps, facial blendshapes, and humanoid animation clips. Use only original or properly licensed assets.
